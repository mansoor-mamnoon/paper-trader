A rulebook, not a promise

How it makes decisions

The worker discovers US exchange-listed symbols and evaluates a rotating batch using delayed daily bars. It does not scan every stock every day. Coverage, missing data and the exact strategy are recorded below.

Signals queue simulated orders for a later completed trading session, not an immediate fill at the signal price. Daily bars cannot establish intraday execution order or guarantee a stop price. No broker connection or real orders.

What this experiment cannot tell you

This is deterministic automation, not an LLM choosing trades. No claim of a profitable edge has been established. Conservative modeled fees and fills still cannot reproduce real liquidity, queue priority, exchange outages or market impact.

This read-only site is hosted on GitHub Pages. GitHub Actions requests an update at 22:37 UTC Monday–Friday, after the US session, plus manual runs. It needs neither this Mac nor an AI subscription. Schedules can be delayed or fail; GitHub provides no uptime guarantee for this experiment. The last successful snapshot remains readable during failures.
